# Marlin для Flying Bear Ghost 6 (MKS Nano4 V3.1)

**Статус: конфиг НЕ компилировался и на принтере НЕ проверялся.** В среде, где он готовился, закрыт реестр PlatformIO. Если сборка выдаст ошибку, пришли текст, и я исправлю конфиг.

База: официальный Marlin `bugfix-2.1.x`, коммит `2d858089937261cbf158530060d50a58db192c5d`. Конфиги подходят только к этому коммиту.

## Что включено
- Плата `BOARD_MKS_ROBIN_NANO_V3_1`, USB-порт, чтение с USB-флешки и SD.
- CoreXY, стол 255×210, высота 210 мм.
- Интерфейс Galaxy UI на экране 480×320 (SPI): плитки, миниатюры G-code, ползунки, русский язык.
- S-curve, Linear Advance (K=0 до калибровки), Input Shaping X/Y (меню на экране), Adaptive Step Smoothing.
- Babystepping, EEPROM, счётчик печати, восстановление после сбоя питания, пауза/смена филамента, парковка.
- Калибровка стола по четырём углам с экрана. Датчика уровня нет.

## Откуда значения
Взято из **вашего стока** (`M503` и `M115`, Marlin 2.0.9.2): шаги X/Y 160.6, Z 800, E 405; максимальные скорости; ПИД хотенда и стола.
Предположения, которые надо проверить:
| Что | Принято | Как проверить |
|---|---|---|
| Драйверы | тип A4988 (универсальный безопасный тайминг) | в стоке `M503` без `M906`: драйверы не настраиваются по UART |
| Направления осей | не инвертированы | тест движения ниже |
| Концевики | срабатывают по LOW | `M119` сразу после прошивки |
| Термисторы | тип 1 (NTC 100K) | температура в комнате 15–30 °C |
| Прямой привод | не учтён | если он есть, калибруй Linear Advance с K≈0.05–0.1 |
| Датчик филамента | выключен | включи `FILAMENT_RUNOUT_SENSOR`, если он есть |
| Экран | 480×320 по SPI (по стоку: размер подтверждён, подключение нет) | если экран не заработает, откат стоком |

## Сборка
**Файл прошивки для вашей платы должен называться `Robin_nano_4.bin`** (так назван сток, и загрузчик ищет именно его).
Вариант A, без установки: загрузи эту папку в свой GitHub-репозиторий, затем Actions → *Build Ghost 6 firmware* → Run → скачай артефакт `Robin_nano_4.bin`.
Вариант B, на ПК: VS Code + PlatformIO, склонировать Marlin на коммит выше, скопировать два `.h` в `Marlin/Marlin/`, собрать окружение `mks_robin_nano_v3_1_usb_flash_drive`. Получится `.pio/build/.../Robin_nano_v3.bin`, **переименуй его в `Robin_nano_4.bin`**.

## Прошивка (шаг за шагом)
1. Сохрани оригинальный архив со стоком в надёжном месте. Это путь отката. (Проверь, что он открывается целиком в WinRAR или 7-Zip.)
2. Выключи принтер совсем (вынь из розетки). Подожди 10 секунд.
3. Отформатируй microSD (8–32 ГБ) в **FAT32, размер кластера 4096 байт**.
4. Скопируй в корень карты **только** `Robin_nano_4.bin`.
5. Вставь карту в слот **на самой плате** (рядом с надписью SD Insert LED), включи принтер.
6. Подожди 30–60 секунд. Экран может быть пустым. Успех: файл на карте переименовался в `Robin_nano_4.CUR`.
7. Выключи, достань карту, включи. Пройди калибровку сенсора (нажми точки на экране).
8. Сразу по USB: `M502`, затем `M500`. Это загрузит настройки новой прошивки и сотрёт старые из EEPROM.
9. Откат: положи стоковый `Robin_nano_4.bin` на карту так же. Если после отката экран без иконок, скопируй рядом папку `assets`.

## Первый запуск (не пропускай)
1. `M119`: в покое все `open`; нажми каждый концевик, должен стать `TRIGGERED`. Если в покое `TRIGGERED`, смени `*_ENDSTOP_HIT_STATE` на `HIGH`. **`G28` пока не делай.**
2. Каретку на середину, затем `M17`, `G91`, `G1 X10 F1000`, `G1 Y10 F1000`, `G1 Z5 F200`. X+ вправо, Y+ к себе, Z+ опускает стол. Иначе меняй `INVERT_*_DIR`. Диагональное движение при одной оси означает, что один из моторов инвертирован. Затем `G90`.
3. Для E: `M104 S200`, дождись нагрева, `G1 E10 F100`, филамент подаётся вперёд.
4. Линейка 100 мм по X и Y (шаги взяты из стока).
5. Первый `G28` с пальцем у выключателя.
6. `M303 E0 S210 C8 U1`, `M303 E-1 S60 C6 U1`, затем `M500`, если ПИД стока не подходит.
7. Linear Advance: `M900 K0.05` и тест-башня. Input shaping: `M593` или меню на экране.
